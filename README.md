## О проекте

Консольный инструмент для подготовки адресной базы и отправки писем через SMTP. Проект объединяет обработку табличных данных, сборку MIME-писем и сохранение состояния между запусками.

Публичная версия обезличена: реальные получатели, аккаунты, пароли, темы, подписи и тексты писем в репозиторий не включены. Демонстрационные адреса используют домены `example.com` и `example.org`.

## Возможности

- Чтение CSV и Excel с поиском столбца email по названию.
- Извлечение до трёх адресов из одной ячейки, приведение к нижнему регистру и удаление дубликатов.
- Необязательный фильтр по домену получателя.
- Отдельные текстовая и HTML-версии письма, встроенные изображения и DOCX-вложение.
- Несколько SMTP-аккаунтов с индивидуальными дневными лимитами.
- Сохранение успешно обработанных адресов и продолжение после перезапуска.
- Предпросмотр по умолчанию: подключение к SMTP требует явного флага `--send`.

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python mailer.py
```

Демонстрационный CSV содержит повтор и некорректную строку. Результат:

```text
✅ Найдено уникальных email: 2
Предпросмотр: 2 уникальных адресов. Отправка отключена.
```

Своя таблица и фильтр по домену:

```bash
python mailer.py --file private/recipients.xlsx --domain example.org
```

Предпросмотр проверяет адресную базу; он не подключается к SMTP и не проверяет доставляемость адресов.

## Настройка отправки

Создайте локальную папку `private/` и скопируйте в неё `examples/accounts.example.json` как `accounts.json`. Укажите свой SMTP-сервер, адрес отправителя и разрешённый вашим провайдером дневной лимит. Для каждого аккаунта поле `password_env` задаёт имя переменной окружения с паролем.

В той же папке создайте собственные файлы:

| Файл | Назначение |
| --- | --- |
| `subject.txt` | Тема письма, одна строка |
| `body.txt` | Текстовая версия |
| `body.html` | HTML-версия |
| `recipients.csv` или `recipients.xlsx` | Адресная база со столбцом `email` |

Установите переменную `MAIL_SMTP_PASSWORD` в своей оболочке, затем запустите:

```bash
python mailer.py --file private/recipients.csv --send
```

Для другого расположения настроек предусмотрены `MAIL_ACCOUNTS_FILE` и `MAIL_CONTENT_DIR`. Состояние сохраняется в `private/email_state.json`. Эта папка исключена из Git.

Необязательные вложения читаются из текущего каталога: `attachment.docx`, `inline_image.png`, `image001.png`. Для картинок в HTML используются маркеры `<!--CERTIFICATE_IMAGE-->` и `<!--IMAGE001-->`. Файлы вложений также исключены из Git.

## Устройство

```text
CSV / Excel → EmailDataProcessor → уникальные адреса
                                         ↓
Локальные настройки → SmartEmailSender → SMTP с STARTTLS
                             ↕
                  private/email_state.json
```

`EmailDataProcessor` отвечает за импорт и очистку. `SmartEmailSender` управляет аккаунтами, дневными лимитами, MIME-вложениями и прогрессом. `create_email()` загружает приватное содержимое, а CLI управляет предпросмотром и отправкой.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют очистку и дедупликацию, пустую адресную базу, восстановление состояния и дневной лимит. GitHub Actions запускает тесты и демонстрационный предпросмотр.

## Ограничения

Состояние хранится в JSON и рассчитано на один запущенный процесс. Это не транзакционная очередь: при аварии между SMTP-доставкой и записью состояния возможна повторная отправка. Лимиты сбрасываются по локальной дате компьютера. Настройка реального механизма отписки остаётся на стороне владельца рассылки; фиктивная ссылка в письма не добавляется.

Используйте инструмент для адресатов, согласившихся получать ваши сообщения, и соблюдайте ограничения почтового провайдера.
